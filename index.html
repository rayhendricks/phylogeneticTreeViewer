Help

Input formats

  • Trees: Newick (with NHX / BEAST [&…] comments), NEXUS (with TRANSLATE, multiple trees), phyloXML.
  • iTOL annotation files: every iTOL dataset type (COLORSTRIP, SIMPLEBAR, MULTIBAR, HEATMAP, GRADIENT, BINARY, EXTERNALSHAPE, TEXT, SYMBOL, PIECHART, DOMAINS, ARROWS, ALIGNMENT, BOXPLOT, LINECHART, CONNECTION, IMAGE, RANGE, TIMESCALE, TANGLEGRAM) and tree file (DATASET_STYLE, TREE_COLORS, LABELS, COLLAPSE, PRUNE, SPACING, METADATA, POPUP_INFO, MULTI_STYLE, AUTO_TAXONOMY). Node IDs can be names, A|B or A---B (last common ancestor) or CONTAINS==regex.
  • Placements: jplace files (each query grafted on its best edge). Motifs: MEME XML output as a domains dataset.
  • Alignments: FASTA files whose sequence names match leaf names.
  • Taxonomy: build a tree from NCBI scientific names or taxonomy IDs.
  • Tables: CSV/TSV with a header row and one row per leaf. Each column becomes a strip, bar, heatmap, presence/absence, text or new display name.
  • Sessions: JSON exported from this app (tree, styles, datasets, settings).

Mouse

  • Click a node or label to select it. Selected nodes show root paths, distances and their last common ancestor.
  • Right-click (or long-press) a node for reroot, collapse, rotate, coloring, pruning and Newick export.
  • Double-click an internal node to collapse or expand it. Drag to pan, scroll to zoom.
